# Glass 🫧

A mobile-first Liquid Glass launcher experiment for Android.

## Current
- Android launcher activity
- Dark glass-inspired home screen
- Circular photo-orb placeholder
- GitHub Actions release build

## Next
- Android photo picker
- Persist multiple photos
- Real circular photo widget
- App drawer and app search
- Glass app icons
- Blur/refraction effects
- Lightweight animations

The project targets Android 8.0+ and is designed to be built from GitHub Actions, so a PC is not required.
